# Jungle Tails — updated Angular source

This archive contains the updated `src` directory from the supplied project, plus this README.

## Changes
- Rebranded visible WILD / ROOT text to **Jungle Tails**.
- Updated the document title and description for Jungle Tails.
- Preserved the five existing experience categories and their route slugs.
- Expanded the India destination catalogue with 15 destination entries.
- Added a destination discovery grid to the Experiences page.
- Added a seasonal discovery section to the homepage.
- Expanded Expeditions, Excursions and Explorations content for India.
- Removed placeholder partner organisation names so the site does not present unverified groups as confirmed partners. The Community page now explains that confirmed collaborations will be published when established.
- Added responsive CSS for the new sections.

## Apply
1. Back up your current project.
2. Extract this ZIP.
3. Copy the included `src` folder into your Angular project root.
4. Allow file replacement when prompted.
5. Do not replace `angular.json`, `package.json`, `tsconfig` files or other workspace configuration; they are not included.
6. Run `ng serve` from your project root.

## Notes
- The destination descriptions and travel windows are general planning guidance, not guaranteed safari availability. Confirm dates, access, park closures, permits and local conditions before publishing trip offers.
- This archive updates the displayed brand only. It does not register `jungle-tails.com`, configure DNS, hosting, SSL or email.
- No Angular dependencies were added.
- The uploaded archive contained only the `src` directory, so a full Angular build could not be run or verified here. Test with your complete project workspace after applying the patch.
